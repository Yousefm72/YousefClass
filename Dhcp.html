بروتوكول DHCP (التوزيع الديناميكي لعناوين الشبكة)

بروتوكول DHCP هو بروتوكول شبكي يقوم بإعطاء الأجهزة إعدادات الشبكة بشكل تلقائي مثل عنوان IP وقناع الشبكة والبوابة الافتراضية وخادم DNS.

لماذا نستخدم DHCP؟

  • تقليل أخطاء الإدخال اليدوي لإعدادات الشبكة.
  • توفير الوقت لمسؤولي الشبكات.
  • إدارة العناوين بكفاءة من خلال نظام التأجير (Lease).

كيف يعمل DHCP؟ (مراحل DORA)

  • Discover: الجهاز يرسل DHCPDISCOVER إلى الشبكة.
  • Offer: الخادم يرسل DHCPOFFER بعنوان متاح.
  • Request: الجهاز يطلب العنوان عبر DHCPREQUEST.
  • Ack: الخادم يؤكد الطلب عبر DHCPACK.

مثال على تسلسل الرسائل

العميل   -> DHCPDISCOVER -> بث عام
الخادم   -> DHCPOFFER    -> العميل
العميل   -> DHCPREQUEST  -> بث عام
الخادم   -> DHCPACK      -> العميل

مثال على بيانات تأجير DHCP

عنوان IP      : 192.168.1.25
قناع الشبكة   : 255.255.255.0
البوابة        : 192.168.1.1
خادم DNS       : 8.8.8.8
مدة التأجير    : 24 ساعة

ملاحظة: يمكن للخادم حجز عنوان ثابت (Reservation) لجهاز معين باستخدام عنوان MAC.

أوامر DHCP لشبكة بسيطة (Router + Switch + VLANs)

المثال التالي يوضح إعداد شبكة تحتوي على راوتر وسويتش و VLANين: Teacher و Student، وكل VLAN فيها 3 أجهزة. تم استخدام NetID أساسي 192.168.1.0 وتقسيمه إلى شبكتين فرعيتين /29.

  • VLAN 10 (Teacher): 192.168.1.0/29 والبوابة 192.168.1.1
  • VLAN 20 (Student): 192.168.1.8/29 والبوابة 192.168.1.9

1) أوامر السويتش (Switch)

enable
configure terminal

vlan 10
 name Teacher
exit

vlan 20
 name Student
exit

interface range fastEthernet 0/1 - 3
 switchport mode access
 switchport access vlan 10
exit

interface range fastEthernet 0/4 - 6
 switchport mode access
 switchport access vlan 20
exit

interface fastEthernet 0/24
 switchport mode trunk
exit

end
write memory

2) أوامر الراوتر (Router-on-a-Stick + DHCP)

enable
configure terminal

interface gigabitEthernet 0/0
 no shutdown
exit

interface gigabitEthernet 0/0.10
 encapsulation dot1Q 10
 ip address 192.168.1.1 255.255.255.248
exit

interface gigabitEthernet 0/0.20
 encapsulation dot1Q 20
 ip address 192.168.1.9 255.255.255.248
exit

ip dhcp excluded-address 192.168.1.1
ip dhcp excluded-address 192.168.1.9

ip dhcp pool Teacher
 network 192.168.1.0 255.255.255.248
 default-router 192.168.1.1
 dns-server 8.8.8.8
exit

ip dhcp pool Student
 network 192.168.1.8 255.255.255.248
 default-router 192.168.1.9
 dns-server 8.8.8.8
exit

end
write memory

3) النتيجة المتوقعة

أجهزة VLAN Teacher تحصل تلقائيًا على IP من مدى 192.168.1.2 - 192.168.1.6، وأجهزة VLAN Student من مدى 192.168.1.10 - 192.168.1.14.

ملاحظة: اجعل كرت الشبكة في أجهزة الـ PC على DHCP/Automatic للحصول على العنوان تلقائيًا.
